# 笔记中枢 P0 实施摘录

完整规格见 `docs/开发文档.md`。本文件只保留 P0 必做。

## 范围

- Obsidian 明文 S3 前缀（Remotely Save 风格）
- 预览 + Postgres FTS
- 本地账号 + 注册时一个 personal Space
- 核心类型、迁移、normalize、preview、一条同步管道

不做：Ask、Skills、思源/Notion/飞书适配器实现、团队空间、向量、S3 事件。

## 硬规则

- 永不写回源 vault
- Preview GET 禁止从源 S3 取正文；只读 canonical/preview + DB
- 无 Ask / Skills / Growth API
- Secrets 永不进入 API 响应
- 忽略 `.obsidian/` 与 `.trash/`
- e2ee=true：status=encrypted_unreadable，跳过正文

## 数据模型（§5）

User, Space(personal|team), SpaceMember(owner|editor|viewer),
Connection(obsidian|siyuan|notion|feishu), Note, Block, Asset, Link,
Chunk(fts tsvector, embedding 预留未用), sync_run, sync_note_log。

P0：注册创建一个人空间。Obsidian source_id：`obsidian://<connection_id>/<posix vault path>`。
重命名：路径即身份；旧行软删，新路径 upsert。
唯一 (connection_id, source_id)。软删除 deleted_at。

Obsidian config：`{ bucket, region, remote_prefix, endpoint, ignore, e2ee }`。
密钥进 secrets 表，经 secrets_ref 引用。

## S3 布局

桶 `hub-dev`：

- source/{space_id}/{connection_id}/
- canonical/{space_id}/{note_id}/note.md, meta.json, assets/
- preview/{space_id}/{note_id}/{hash}.html

夹具 vault（vault1/）：Welcome.md、Daily/2026-08-29.md、assets/sample.png；
`.obsidian/app.json` 与 `.trash/deleted.md` 必须忽略。

## 管道

probe → listChanges(ListObjectsV2 + ETag) → fetch → source 镜像 → normalize → hash 跳过 → canonical+DB → preview → FTS chunks。
单篇失败不中止整批。jobId = sync:{connection_id}。

Normalize：YAML frontmatter、wiki `[[]]` / `![[]]`、markdown 链接。
无原生块 id：source_block_id = heading 路径 + 段序号 + 文本指纹。
Preview 锚点 `id="b-{source_block_id}"`。不执行笔记脚本。
