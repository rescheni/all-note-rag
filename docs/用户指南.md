# 笔记中枢 · 用户指南

面向日常使用者。部署与环境变量见仓库根目录 [README.md](../README.md)；设计细节见 [开发文档.md](./开发文档.md)。

中枢是 **只读聚合**：在思源 / Notion / 飞书 / Obsidian 里写作，在这里浏览、搜索、提问。改内容请回源应用。

## 1. 注册与登录

1. 打开站点（本机默认 http://127.0.0.1:3000）。
2. **注册**：邮箱 + 密码；系统会自动创建你的 **个人空间**。
3. **登录**后进入首页：热力图、连接书架、快捷入口。

忘记密码需管理员侧重置（当前无自助找回邮件）。子账号由所有者在 **账号** 页创建，用子账号邮箱密码登录即可。中枢为个人只读笔记中枢，无团队协作。

## 2. 接入各源

导航 **接入** → 选源，或首页书架旁新建连接。保存后点 **同步**；进度会显示文件 / 数据块。

### 思源

- **HTTP 内核**：填内核地址与 token（只读权限即可）。
- **明文 data 前缀**：兼容对象存储上的 workspace。
- **官方 S3 快照**：填写数据仓库密码后只读摄入最新 `.sy` 快照。

### Notion

1. 优先 **用 Notion 登录授权**（需部署方配置 OAuth）；或展开高级项填 **Integration Token**。
2. **重要**：只能同步 **已分享给该 Integration 的页面 / 数据库**。
3. 缺页时：打开 Notion → 该页 **Share** → 邀请你的 Integration（或 OAuth 时勾选更多页）→ 回中枢再同步。

### 飞书

1. 优先 **用飞书扫码登录**（官方扫码页）。知识库同步需要 **用户身份**。
2. 可粘贴知识库或页面链接（feishu.cn/wiki/...）收窄范围。
3. 仅填 App ID/Secret、不扫码时：应用必须是知识库成员，否则会报无权列举节点。
4. 授权失效时在同一连接上重新扫码即可（保留增量游标与已有笔记，不会整库重拉）。

### Obsidian

填写 S3 兼容 Endpoint、Bucket、vault 前缀与密钥。支持但 **非优先**。开启端到端加密的库无法读正文。

## 3. 书架阅读

1. **首页**：每条连接像一本立着的书；可看篇数与最近同步。
2. **笔记 → 书架**：按连接成「书」；点开进入文件夹树。
3. 面包屑会尽量显示 **标题而不是原始 ID**（路径人话化）；可逐级返回或「放回书架」。
4. 打开一篇笔记：Markdown 预览；支持双链、块引用跳转与页脚 **反向链接**。
5. 附件（图、pdf 等）随笔记展示；图片等可经 OCR 进入检索（取决于部署）。

## 4. 搜索与问答

- **搜索**：关键词、路径片段、全文；结果区分命中文件与 **相似文件**（向量）。
- **问答（Ask）**：基于检索作答，并附 **来源卡片**；点击可跳到预览中的块锚点。
- **已配置 AI**（设置里 Base URL + Key + 对话模型）：走 Chat Completions，回答为模型生成并附引用；上游失败（额度、鉴权、超时）会返回**明确中文错误**，不再静默改成抽取。
- **未配置 AI**：本地抽取式作答，并提示去设置。

写作仍在思源 / Notion / 飞书 / Obsidian；中枢只读聚合与问答。

主导航不含「会议 / 写作 / Skills」（路由仍可打开说明页）。

## 5. 主题与 AI 模型

左侧导航的 **设置**（齿轮）入口即可打开本页（AI、主题、氛围）。

### 主题

打开 **设置**，选择：

| 主题 | 说明 |
|------|------|
| **抹茶纸色** | 默认。暖日宣纸、苔藓缝线 |
| **墨夜** | 深色阅读：暖墨底、淡纸字，夜里不刺眼 |
| **素白** | 更安静的浅色，少一点暖黄 |

选择后会同步到账号。墨夜适合夜间长时间阅读。

### AI 模型

在 **设置 → AI**：

1. 填写 OpenAI 兼容的 Base URL 与 API Key（也可依赖服务端环境变量）。
2. 点 **刷新模型列表**，从上游拉取可选模型。
3. 分别选择对话模型与嵌入模型后保存。

未配置时：问答抽取式；嵌入用本地投影，不打外网。
已配置但上游报错（例如额度不足）：问答页会显示错误，请检查服务商控制台或 Key。

## 6. 账号、子账号、API Token 与 MCP

### 子账号

个人空间可在 **账号** 页 **创建子账号**（新邮箱+密码），供 Agent / 只读或编辑共用；不会为子账号再建一套个人空间。无团队成员协作。

### API Token（给 Agent / 脚本）

1. 打开 **账号** 页。
2. 创建令牌并起名（例如「本地 Agent」）。
3. **明文只显示一次**，请立刻复制保存。格式为 `hub_` 开头。
4. 调用时：`Authorization: Bearer hub_…`。

也可用登录 JWT，或 HTTP Basic（邮箱:密码）。示例：

```
curl -H "Authorization: Bearer hub_你的令牌" https://你的域名/v1/me
curl -u "you@example.com:password" https://你的域名/v1/me
```

### MCP（外部 AI）

1. 在账号页创建 `hub_` 令牌。
2. MCP URL：`https://你的域名/v1/mcp`（本机 `http://127.0.0.1:3001/v1/mcp`）。
3. 在 Cursor 的 `mcp.json` 里填 URL + `Authorization: Bearer hub_…`。

工具：`search_notes`、`get_note`、`list_connections`、`list_spaces`。详见 [MCP.md](./MCP.md)。

### 文档可见性

私人笔记默认 **仅自己** 可见。中枢不做团队协作分享。

## 7. 常见问题

### Notion 同步不全？

几乎都是 **未 Share 给 Integration**。在 Notion 里把缺的页面分享给集成后再同步。OAuth 也只包含授权时勾选的范围。

### 路径像一串 ID，不好认？

中枢会尽量把面包屑 **人话化**（用树节点标题替换 ID 前缀）。若仍难看，多半是源侧标题未同步完——等同步结束或打开父级文件夹再试。

### 墨夜主题在哪？

设置里选 **墨夜**。若看起来仍是浅色，确认已登录且主题已保存；强制刷新一次页面。

### 飞书提示无权访问知识库？

先 **扫码登录**；确认当前飞书账号能在飞书客户端打开该知识库。仅用应用凭证时，把应用加为知识库成员。

### 预览和源里不一致？

中枢读的是上次同步的缓存。回源应用保存后，可手动点同步；对象存储变更会唤醒同步；自动巡检约每小时一次（距上次同步超过约 1 小时才跑）。中枢 **不会** 写回源。

### 搜索搜不到图里的字？

需要 Worker 完成 OCR。Compose 部署通常已带 tesseract；本机开发可能较慢。

### PWA 如何安装？

用支持的浏览器打开站点，按「安装应用」或「添加到主屏幕」。
